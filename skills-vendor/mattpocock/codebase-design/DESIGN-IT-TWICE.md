# Design It Twice

When comparing alternative interfaces, read `../design-an-interface/SKILL.md` for the shared method. Frame the caller needs, invariants and compatibility constraints first; use the project's domain language and this skill's architecture vocabulary.

For a deepening candidate, read `DEEPENING.md` to classify dependencies and include each candidate's dependency strategy. Compare depth, locality and seam placement, then recommend a design. Parallel agents are optional, not a required step.
