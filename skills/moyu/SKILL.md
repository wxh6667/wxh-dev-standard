# 修改范围审查

对照用户目标和当前差异，区分必要修改与无关扩展。优先复用已有实现，撤回本次自行添加且确认不必要的功能、抽象、依赖和格式改动，保留用户已有工作。

范围以完成目标所需的行为判断，不按文件数或 diff 行数裁决。关联文件修复、真实错误处理和必要验证可以属于同一目标，不因用户没有逐项点名而省略。

确认所有保留的修改都有目的、必要验证仍覆盖关键行为，并说明删减了什么及是否留下限制。影响授权或会显著改变目标的取舍再询问；已经授权的工作继续执行。
