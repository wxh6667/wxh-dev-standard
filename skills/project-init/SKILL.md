# Project Init Skill

## Purpose

初始化新项目，让 AI 在修改代码前理解项目。

## Trigger

- 新项目开始
- 接手已有项目
- AI 第一次进入代码库

## Workflow

1. 扫描项目目录
2. 识别技术栈
3. 分析前端、后端、数据库、部署方式
4. 检查已有文档和规则
5. 初始化项目上下文

## AI Context

检查：

- AGENTS.md
- 项目规则
- CodeGraph
- Trellis 或同类项目索引工具

未完成项目上下文初始化前，不进行大规模重构。

## Output

输出项目分析结果和后续开发计划。
