# 库文档查询

先从依赖文件或用户信息确定目标版本，再查询影响当前实现的具体问题。Context7 是文档检索通道，事实以对应版本的官方文档、类型和源码核对，不把检索工具当作唯一权威。

## 查询方法

1. 已有专业文档工具或 Skill 能取得目标版本的一手资料时直接使用，不重复查询。OpenAI 产品优先使用官方文档工具；Claude / Anthropic 问题有可用官方能力时使用它。
2. 使用 Context7 时先 `resolve-library-id` 确认库，再 `query-docs` 查询具体主题；名称有歧义时注明生态和版本。
3. 结果与项目版本或其他一手材料冲突时，核对版本及原始出处。无法确定时说明冲突，不猜测。
4. 查不到或查询失败时使用官方文档站、已安装类型或源码，必要时搜索官方资料；明确失败或覆盖缺口。

引用 API 行为时说明适用版本。项目内部事实用本地工具确认，离线任务遵守用户资料范围。已经取得足够、适用的证据时停止检索。
