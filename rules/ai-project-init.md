# AI Project Initialization Standard

## 目的

项目进入 AI Coding 开发前，需要先初始化项目级上下文，避免 AI 在不了解项目结构、技术栈和业务逻辑的情况下直接修改代码。

## 初始化要求

开始开发前检查：

- 项目结构是否已经分析
- 前后端技术栈是否确认
- 数据库结构是否理解
- 部署方式是否确认
- 项目级 AI 上下文是否初始化

支持各种 AI 工具，包括但不限于：

- CodeGraph
- Trellis
- Cursor Rules
- Claude Code Rules
- Codex 项目规则

## 规则

如果项目级上下文未初始化：

1. 先执行项目扫描和分析
2. 建立代码关系和目录理解
3. 初始化项目规则文件
4. 再开始功能开发或大范围修改

禁止：

- 未分析项目直接重构
- 不理解已有业务直接替换代码
- 随意新增重复脚本和目录

## 修改原则

优先：

- 修改已有代码
- 保持已有部署方式
- 保持项目结构稳定
- 最小化变更

新增文件必须说明原因。
